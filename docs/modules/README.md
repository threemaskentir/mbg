# Dokumentasi Modul — MB Guardian (Mockup Interaktif)

Panduan penggunaan **per modul** untuk mockup interaktif sistem monitoring
**Makan Bergizi Gratis (MBG)**. Setiap dokumen berisi tujuan, peran yang
mengakses, lokasi di aplikasi, dan **langkah-demi-langkah** menjalankan alurnya.

> ⚡ Seluruh data bersifat **dummy**. Fitur OCR, GPS, analisis sentimen, dan
> analisis kamera dapur adalah **simulasi** untuk demo — bukan layanan produksi.
